# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Electron (Web MIDI, Web Audio, WebGL2). Chosen by the user for Windows + Linux support with the least code.

## Users

A player performing live, with the screen projected for an audience or a stream. Any MIDI controller.

## Product Purpose

Turn whatever someone plays into an ethereal sound and a matching abstract visual. Constant ambient strings underneath, a soft but punchy celesta-like voice on top.

## Operating Context

Fullscreen on a projector or second display, cursor hidden, no visible chrome while performing. One status line appears only for device changes or errors.

## Product Principles

- The performance owns the screen: no persistent UI.
- Sound and image share one harmonic logic: circle-of-fifths color, and the pad follows the player's key.
- Never silent, never still: the ambience and the visuals keep moving when nobody is playing.
